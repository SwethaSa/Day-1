# Task Submission: HTTP & JavaScript Objects

=> Task Description:
    Write a blog on Difference between HTTP1.1 vs HTTP2
    Write a blog about objects and its internal representation in Javascript
    codekata practice

This repository contains my full-stack course task, broken into two separate blog files and a README to explain everything.

## Files Included

1. http.md
   - A simple Readme explaining the differences between HTTP/1.1 and HTTP/2.  
   - Covers key features like binary framing, multiplexing, headr compression, server push, and why these changes matter for page speed.

2. objects.md 
   - A blog on JavaScript objects and how engines store them.  
   - Explains hidden clases (“shapes”), inline caches, fast vs dictionary storage.
